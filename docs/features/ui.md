# Feature: PyQt UI

## Назначение
UI обеспечивает интерактивный контроль за прогоном тестов, выбор профилей и визуализацию результатов для исследовательских и демонстрационных сценариев, как описано в DOC1/DOC2 (режим исследователя vs. демонстрация).

## Архитектура
- `application/controller.py` – `UISuiteController`, фасад над `TestSuiteService`.
- `presentation/main_window.py` – главное окно PyQt:
  - выбор профиля,
  - мультивыбор категорий и тестов,
  - запуск тестов и A/B прогонов,
  - таблица результатов с Pass/Fail, решением защиты, причиной.
- `presentation/main.py` – entrypoint `llm-security-ui`.

## Поток работы
1. При запуске UI загружает список тестов и профилей (`controller.load_initial_data`).
2. Пользователь выбирает категории / конкретные тесты.
3. При нажатии «Запустить профиль» запускается `run_suite`.
4. При нажатии «A/B прогон» вызывается `run_ab`, отображается `Δ Pass%`.
5. Таблица результатов обновляется в реальном времени, метрика Pass% выводится в статусной области.

## Особенности UX
- Поддержка фильтрации (через чекбоксы категорий).
- Возможность выделять конкретные тесты для точечного прогона.
- Отображение решения защиты (`defense_decision`), что демонстрирует вклад слоёв (например, `block`, `rewrite`).
- В случае ошибок – диалог `QMessageBox` с сообщением (например, проблемы сети).

## Требования
- Python 3.10+, PyQt6.
- Подключение к реальной модели не обязательно: UI работает с `DummyModelClient`.
